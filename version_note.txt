VERSION: D-0.0.1
Release Date : 2026-09-17
Platform     : Cross-Platform (Windows, Linux, macOS)
Status       : Stable Initial Release
================================================================================

1. OVERVIEW
Mail Quota Manager is a lightweight, cross-platform email quota and reset date
tracker. It operates with a web-based user interface backed by an isolated
local SQLite database and self-contained zero-dependency portable runtime.

2. KEY FEATURES & HIGHLIGHTS (D-0.0.1)
* Web Interface:
  - Dark Mode & Light Mode toggle with preference saved in localStorage.
  - Interactive table header column sorting (A-Z, Z-A) for Email, Date, Status.
  - Real-time search/filter for emails and reset dates.
  - Visual status chips ("Available" in green vs "Waiting" in amber).
  - Inline date editor and delete confirmation.

* Background Process & Lifecycle:
  - Windows: Runs decoupled using pythonw.exe; CMD window can be closed freely 
    without stopping the web application.
  - Linux/macOS: Background nohup daemon process.
  - Single-browser tab launch (fixed duplicate window opening on startup).
  - Safe localhost-only graceful shutdown via the "Quit App" button in the UI.

* Security & Data Integrity:
  - Strict RFC-compliant email regex validation preventing malformed & XSS payloads.
  - Strict ISO-8601 date parsing (YYYY-MM-DD).
  - SQL parameterized queries preventing SQL injection vulnerabilities.
  - HTML entity escaping (esc()) in UI rendering.
  - SQLite WAL (Write-Ahead Logging) mode and foreign keys enabled.
  - Case-insensitive duplicate email prevention (COLLATE NOCASE).

* Cross-Platform Portable Scripts (cmdS/):
  - run.bat / run.sh: Auto-bootstraps self-contained Python runtime on demand.
  - clean.bat / clean.sh: Safe cache & runtime cleanup while preserving data.
